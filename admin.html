Редактор персонажей

Добавляйте персонажей, меняйте имя, возраст, способности, описание и изображение. После сохранения изменения отправляются прямо в ваш репозиторий GitHub.

1. Подключение к GitHub

Токен используется только в этой вкладке и не записывается в файлы сайта.

Не проверено
Как создать безопасный токен GitHub
  1. В GitHub откройте аватар → Settings.
  2. Откройте Developer settings → Personal access tokens → Fine-grained tokens.
  3. Нажмите Generate new token.
  4. В Repository access выберите только репозиторий сайта.
  5. В Repository permissions установите Contents: Read and write.
  6. Создайте токен, скопируйте его и вставьте выше.

Никому не отправляйте токен. Не добавляйте его в HTML, JavaScript, сообщения и скриншоты.

2. Персонажи

Заполните карточки и выберите изображения JPG, PNG или WEBP.

Готово к публикации?
