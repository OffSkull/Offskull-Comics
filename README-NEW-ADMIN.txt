OFFSKULL COMICS — НОВЫЙ ВХОД АДМИНИСТРАТОРА

ЧТО ИЗМЕНИЛОСЬ
--------------
1. Старый вход через GitHub-токен удалён.
2. На сайте осталась одна кнопка «Вход администратора».
3. Вход выполняется по вашему логину и паролю через Supabase.
4. Обычным пользователям вход не нужен.
5. Все посетители могут читать комиксы и смотреть персонажей.
6. Только администратор может:
   - добавлять и редактировать персонажей;
   - загружать фотографии;
   - менять описания и способности;
   - добавлять комиксы;
   - менять обложки;
   - создавать выпуски;
   - загружать страницы комиксов.

ВАЖНО
-----
GitHub Pages не умеет безопасно проверять пароль самостоятельно.
Поэтому пароль проверяет Supabase, а правила RLS разрешают изменение
данных только аккаунту администратора.

НАСТРОЙКА SUPABASE
------------------
1. Создайте проект на supabase.com.
2. Откройте SQL Editor.
3. Выполните файл supabase/1-SETUP.sql.
4. Откройте Authentication → Users → Add user.
5. Придумайте логин в виде e-mail и пароль.
   Например: admin@offskull.ru
6. В файле supabase/2-ADD-ADMIN.sql замените:
   YOUR_ADMIN_LOGIN@example.com
   на ваш логин.
7. Выполните файл supabase/2-ADD-ADMIN.sql.
8. В Supabase откройте Project Settings → API.
9. Скопируйте Project URL.
10. Скопируйте Publishable key или anon public key.
11. Откройте assets/js/supabase-config.js.
12. Вставьте URL и ключ в соответствующие поля.
13. Никогда не вставляйте service_role key.

УСТАНОВКА НА GITHUB
-------------------
1. Распакуйте архив обновления.
2. Откройте корень репозитория сайта.
3. Add file → Upload files.
4. Загрузите всё содержимое распакованной папки.
5. Нажмите Commit changes.
6. Откройте сайт и нажмите Ctrl + F5.

ПЕРВЫЙ ВХОД
------------
1. Нажмите «Вход администратора».
2. Введите созданный логин и пароль.
3. Откроется admin.html.
4. Нажмите «Сохранить на сайт» хотя бы один раз.
   Текущие данные из content.js будут перенесены в Supabase.
