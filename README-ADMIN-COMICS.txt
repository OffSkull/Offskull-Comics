OFFSKULL COMICS — ОБНОВЛЕНИЕ АДМИН-ПАНЕЛИ

ЧТО ДОБАВЛЕНО
-------------
В панели администратора появился раздел «Комиксы».

Через сайт теперь можно:
- создать новый комикс;
- изменить название, ID, жанр, возраст, статус и описание;
- заменить обложку;
- добавить несколько выпусков;
- изменить номер, название и дату выпуска;
- выбрать сразу несколько страниц;
- менять порядок страниц стрелками;
- удалить страницу из выпуска;
- удалить выпуск;
- удалить комикс;
- продолжать редактировать персонажей.

КАК УСТАНОВИТЬ
--------------
1. Распакуйте архив offskull-admin-comics-update.zip.
2. Откройте корень репозитория сайта на GitHub.
3. Нажмите Add file → Upload files.
4. Перетащите:
   - admin.html
   - папку assets
   - README-ADMIN-COMICS.txt
5. Нажмите Commit changes.
6. Откройте admin-login.html и войдите как администратор.
7. Откройте admin.html.
8. Нажмите Ctrl + F5.

КАК ДОБАВИТЬ КОМИКС
-------------------
1. В админке выберите вкладку «Комиксы».
2. Нажмите «+ Добавить комикс».
3. Заполните название, ID, описание, жанр, возраст и статус.
4. Нажмите «Выбрать новую обложку».
5. Нажмите «+ Добавить выпуск».
6. Заполните номер, название и дату выпуска.
7. Нажмите «+ Выбрать страницы».
8. Выберите JPG, PNG, WEBP или GIF.
9. При необходимости поменяйте порядок стрелками.
10. Нажмите «Сохранить на сайт».

ВАЖНО
------
- ID комикса пишется английскими буквами: viking, liga-smeha.
- Размер одного изображения — не больше 20 МБ.
- Новые файлы загружаются в assets/images/comics.
- Удаление карточки из админки не удаляет старые картинки из GitHub.
  Они остаются как резервная копия.
- Токен должен иметь Contents: Read and write.
