OFFSKULL COMICS — ПОЛНАЯ РАБОЧАЯ ВЕРСИЯ

ЧТО ВНУТРИ
- Главная страница с баннером и большой новостью.
- Каталог всех комиксов.
- Отдельная страница каждого комикса.
- Вертикальная читалка: страницы листаются сверху вниз.
- Персонажи.
- Страница автора.
- Отдельный вход администратора.
- Админка для:
  * изменения новости и её изображения;
  * изменения имени, описания и фотографии автора;
  * добавления/удаления/редактирования комиксов;
  * изменения обложек;
  * добавления выпусков;
  * загрузки страниц комикса;
  * изменения порядка страниц;
  * добавления/удаления/редактирования персонажей и фотографий.

КАК ПОЛНОСТЬЮ ЗАМЕНИТЬ САЙТ
1. Скачайте архив и распакуйте папку offskull-comics-complete.
2. Сохраните копию старого репозитория.
3. В GitHub удалите старые файлы сайта или создайте новый пустой репозиторий.
4. Загрузите ВЕСЬ КОНТЕНТ папки offskull-comics-complete в корень репозитория.
5. В корне должны находиться index.html, comic.html, characters.html и assets.
6. Settings → Pages → Deploy from a branch → main → /(root) → Save.
7. Подождите зелёную галочку в Actions.
8. Откройте сайт и нажмите Ctrl + F5.

САЙТ РАБОТАЕТ БЕЗ SUPABASE
Публичные страницы сразу покажут встроенные комиксы, обложки и персонажей.
Без Supabase не будет работать только вход администратора и сохранение изменений.

НАСТРОЙКА АДМИНКИ
1. Создайте проект Supabase.
2. Откройте SQL Editor и выполните supabase/SETUP.sql.
3. Authentication → Users → Add user.
4. Создайте пользователя с вашим e-mail и паролем.
5. В SQL Editor выполните:

insert into public.site_admins (user_id)
select id from auth.users
where lower(email) = lower('ВАШ_ЛОГИН@example.com')
on conflict (user_id) do nothing;

6. Project Settings → API:
   скопируйте Project URL и Publishable key.
7. Откройте assets/js/supabase-config.js.
8. Вставьте URL и ключ. Никогда не вставляйте service_role key.
9. Откройте admin-login.html и войдите.
10. Нажмите «Сохранить на сайт» — стартовые данные перенесутся в Supabase.

ВАЖНО
- Кнопка «Восстановить стартовые данные» возвращает три комикса и шесть персонажей.
- Обычным читателям вход не нужен.
- Максимальный размер одного изображения: 20 МБ.
