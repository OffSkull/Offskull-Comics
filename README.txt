OFFSKULL COMICS — ГОТОВАЯ ПЕРВАЯ ВЕРСИЯ САЙТА

КАК ОТКРЫТЬ САЙТ
1. Распакуйте архив.
2. Откройте папку offskull-comics.
3. Дважды нажмите на файл index.html.
4. Сайт откроется в браузере.

ГДЕ МЕНЯТЬ ТЕКСТЫ
Откройте файл:
assets/js/content.js

В нём можно изменить:
- название и описание сайта;
- имя автора;
- описание автора;
- названия и описания комиксов;
- жанр и возрастное ограничение;
- персонажей;
- список выпусков;
- список страниц каждого выпуска.

КАК ЗАМЕНИТЬ ОБЛОЖКУ
1. Поместите новую обложку в папку assets/images/comics.
2. Лучше использовать JPG, PNG или WEBP.
3. В content.js замените путь cover на путь к вашему файлу.

Пример:
cover: "assets/images/comics/moya-oblozhka.jpg"

КАК ДОБАВИТЬ СТРАНИЦЫ КОМИКСА
1. Положите изображения страниц в нужную папку.
2. Назовите их по порядку: page-1.jpg, page-2.jpg и так далее.
3. В content.js добавьте пути в массив pages.

Пример:
pages: [
  "assets/images/comics/my-comic/issue-1/page-1.jpg",
  "assets/images/comics/my-comic/issue-1/page-2.jpg"
]

КАК ДОБАВИТЬ НОВЫЙ КОМИКС
Скопируйте существующий объект комикса в массиве comics внутри content.js.
Измените:
- id;
- title;
- cover;
- description;
- genre;
- age;
- status;
- issues.

ID должен быть написан латинскими буквами без пробелов.

КАК ОПУБЛИКОВАТЬ БЕСПЛАТНО ЧЕРЕЗ GITHUB
1. Зарегистрируйтесь на github.com.
2. Создайте новый репозиторий.
3. Назовите его offskull-comics.
4. Загрузите в него всё содержимое папки сайта.
5. Откройте Settings → Pages.
6. В разделе Source выберите Deploy from a branch.
7. Выберите ветку main и папку /root.
8. Нажмите Save.
9. Через некоторое время GitHub покажет публичную ссылку.

ВАЖНО
Не меняйте названия папок assets, css и js, если не меняете пути в HTML-файлах.


ПАНЕЛЬ АДМИНИСТРАТОРА
---------------------
Адрес панели после публикации:
https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/admin.html

Пример:
https://offskullcomics.github.io/offskull-comics/admin.html

Через панель можно:
- добавить нового персонажа;
- изменить имя, возраст, способности и описание;
- выбрать JPG, PNG, WEBP или GIF;
- удалить карточку персонажа;
- сохранить изменения прямо в GitHub;
- скачать резервную копию данных.

КАК СОЗДАТЬ ТОКЕН
1. Откройте GitHub.
2. Нажмите аватар → Settings.
3. Откройте Developer settings.
4. Откройте Personal access tokens → Fine-grained tokens.
5. Нажмите Generate new token.
6. Выберите только репозиторий offskull-comics.
7. В Repository permissions включите Contents: Read and write.
8. Создайте токен и скопируйте его.
9. Вставляйте токен только на странице admin.html.

ВАЖНО О БЕЗОПАСНОСТИ
- Токен похож на пароль.
- Не вставляйте токен в HTML, content.js или admin.js.
- Не отправляйте его другим людям.
- Не публикуйте скриншоты с открытым токеном.
- После работы можно отозвать токен в настройках GitHub.
