Вход для администратора

Войдите с помощью GitHub-токена, чтобы редактировать персонажей, загружать изображения и сохранять изменения на сайте.

Где получить токен
  1. GitHub → аватар → Settings.
  2. Developer settings → Personal access tokens.
  3. Откройте Fine-grained tokens и создайте новый токен.
  4. Разрешите доступ только к репозиторию сайта.
  5. Включите разрешение Contents: Read and write.

Токен хранится только в текущей вкладке браузера и удаляется после выхода или закрытия вкладки.
